# Collection Pages

This folder defines the category, collection and search-result experience for Sunless by Jimmy Coco.

The collection system must help customers choose quickly without collapsing into a generic ecommerce grid. It should preserve the premium editorial character of the brand while keeping product discovery, comparison and purchase intent extremely clear.

## Documents

- `00-master-architecture.md` — overall page structure and narrative
- `01-collection-hero-and-introduction.md` — category framing and editorial entry
- `02-product-grid-and-card-system.md` — product-card hierarchy and grid behaviour
- `03-filter-sort-and-shade-guidance.md` — filtering, sorting and guided selection
- `04-merchandising-and-featured-products.md` — product ordering and editorial merchandising
- `05-empty-loading-and-no-results-states.md` — system states and recovery paths
- `06-mobile-collection-page.md` — mobile-specific architecture
- `07-final-ai-collection-page-prompt.md` — final image-generation prompt

## Core principle

Collection pages are commercial tools first and editorial environments second. Products must remain visible, comparable and purchasable without sacrificing the calm, refined and expert-led Sunless brand experience.
