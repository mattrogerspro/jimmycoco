# 10 — Final AI Shade-Match Prompts

## Production rule

Generate the questionnaire and results experience as separate screens. Use the approved Sunless website, product references, shared brand system and relevant website design-system documents as strict inputs. Rebuild production text as live UI after visual generation.

## Prompt A — Desktop Questionnaire

Create one ultra-premium 1700px-wide desktop ecommerce interface for **Sunless by Jimmy Coco** showing an active **Shade Match consultation**.

Preserve the existing brand identity: warm ivory, linen, stone and champagne tones, elegant editorial serif headings, refined sans-serif interface copy, matte-black calls to action, natural beauty photography and restrained luxury styling.

The screen must feel like a calm professional consultation, not a generic quiz, survey, lead form or game.

Use a spacious full-screen composition with a quiet header, discreet exit action, refined progress line and the label **“Question 2 of 6.”** Present one clear question: **“What kind of result would you like?”**

Show four large answer cards:

- Subtle warmth
- Natural sun-kissed colour
- Deeper bronze
- Event-ready intensity

Use accurate, consistently lit visual references and clear text labels. Show a visible selected state using border, fill and a small check indicator. Add a quiet **“Not sure”** option beneath the main choices.

Place **Back** and one dominant matte-black **Continue** button in a stable lower action area. Keep the layout highly legible, spacious and commercially polished.

No glassmorphism, neon gradients, gamified progress circles, cartoon icons, confetti, pseudo-scientific scanning visuals, tiny text, crowded cards or email capture.

## Prompt B — Desktop Results Page

Create one ultra-premium 1700px-wide ecommerce results page for **Sunless by Jimmy Coco** titled **“Your best match.”**

Use the approved website, product packaging and shared design system as strict references. Make the result immediately commercial: the customer must see what was recommended, why it suits them and how to buy it.

Build the opening scene as a confident split composition. On the left, show one accurate hero product render with restrained supporting media. On the right, create the purchase and recommendation panel.

Include:

- **YOUR BEST MATCH** label;
- accurate product name and preselected variant;
- concise suitability statement;
- verified review summary;
- price;
- quantity control;
- one dominant matte-black **ADD TO BAG** button;
- quieter product-details link;
- delivery and returns reassurance.

Directly below, add a refined **“Why this matches”** section with four compact reasons: desired depth, application control, development timing and intended use. Add expected-result guidance with recommended number of coats, development time and how to adjust the finish.

Continue with three distinct chapters:

1. **Results like yours** — a small set of verified result references with useful context.
2. **Prefer a more gradual build?** — one quieter alternative with a clear trade-off.
3. **Complete your routine** — restrained Prepare, Apply and Perfect recommendations, maximum one item per stage.

Finish with **Review my answers** and optional **Email my result** controls only after the complete recommendation is already visible.

Do not create a giant decorative hero, fake match percentages, medical claims, generic product grids, multiple competing recommendations, excessive badges or preselected optional bundles.

## Prompt C — Mobile Questionnaire

Create one premium mobile Shade Match screen for **Sunless by Jimmy Coco**, approximately 390px wide.

Show a compact header, close action, restrained progress indicator and one question per screen. Use **“What kind of result would you like?”** with four vertically stacked full-width answer cards and a quiet **Not sure** option.

Place Back and a large matte-black Continue button in a sticky lower action area above the safe zone. Keep text readable, touch targets generous and the interface calm. No horizontal scrolling, tiny mosaics, decorative animation or email capture.

## Prompt D — Mobile Results

Create one premium mobile Shade Match results page for **Sunless by Jimmy Coco**, approximately 390px wide.

Place **“Your best match”** at the top, followed immediately by one accurate product image, product name, preselected variant, result statement, price, verified review summary and a dominant **ADD TO BAG** button.

Below, show compact sections for **Why this matches**, **Your expected result**, **Results like yours**, one meaningful alternative and the Prepare–Apply–Perfect routine. After the main purchase block scrolls away, use a compact sticky bar with product shorthand, selected variant, price and Add to Bag.

## Universal negative prompt

Do not generate orange or artificial-looking results, inconsistent product packaging, distorted labels, fake logos, generic Shopify styling, flat beige with no contrast, glassmorphism, neon gradients, gamified quiz graphics, fake AI analysis, percentage match claims, email gates, discount pop-ups, countdown timers, excessive trust badges, several competing primary recommendations, inaccessible contrast, tiny text, unclear selected states or automatically added optional products.

## Approval tests

Every concept must pass:

- immediate recommendation comprehension;
- clear selected variant;
- obvious Add to Bag;
- transparent reasoning;
- accurate product references;
- realistic imagery;
- no unsupported claims;
- accessibility risk review;
- consistency with product pages, collection pages and cart;
- preservation of the Sunless identity.
