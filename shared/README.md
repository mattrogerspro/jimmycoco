# Shared Sunless Creative System

This folder contains brand rules, assets and production standards that apply across every Sunless channel, including the website, email templates, lifecycle sequences, campaigns and future digital touchpoints.

## Planned structure

- `00-brand/` — core brand DNA, positioning, personality, tone and approved claims
- `01-visual-language/` — shared colour, typography, photography, iconography and product-rendering rules
- `02-copy-language/` — voice, terminology, message hierarchy, claims and prohibited language
- `03-assets/` — logos, product references, Jimmy Coco references, model references and asset manifests
- `04-production/` — universal AI consistency protocol, QA rules, file naming and approval status

## Ownership rule

Place a rule in `shared/` when it must remain consistent across more than one channel. Keep channel-specific composition, interaction, conversion flow and templates inside `website/` or `email/`.

Avoid duplicating shared rules. Channel documentation should link back to the canonical shared document.
