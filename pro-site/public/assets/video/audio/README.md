# Jimmy Coco Pro video audio

Only licensed, commissioned or otherwise approved audio belongs in this folder.

- `voiceover/<campaign-slug>.mp3` — final narration, beginning at video frame 0.
- `music/<track-name>.mp3` — licensed instrumental bed with documented usage rights.

After adding a file, set its path in
`pro-site/video/src/content/storyboards.json`. Production renders keep audio off
unless `--audio mastered` is explicitly supplied.
