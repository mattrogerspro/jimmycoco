# www.jimmycoco.pro — crawl policy
# Two rules to keep in mind before editing:
#  1. Groups do not inherit. A crawler matching a named User-agent group
#     ignores the "*" group entirely, so the Disallow list is repeated in
#     full for every group below. Do not "tidy" that away.
#  2. There is deliberately no "Allow: /" line. Anything not disallowed is
#     already allowed, and an explicit Allow: / is read as overriding the
#     disallows by older first-match-wins parsers.
