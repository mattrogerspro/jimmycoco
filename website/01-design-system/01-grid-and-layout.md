# 01 — Grid and Layout System

## Purpose

This document defines the structural rules that keep the Sunless website coherent while allowing each homepage chapter to have a distinct editorial silhouette.

The grid is a control system, not a visual cage.

## Desktop canvas

Primary design reference:

- Artboard width: 1700px
- Core content width: approximately 1440–1500px
- Outer margins: approximately 100–130px depending on chapter
- Invisible columns: 12
- Standard gutter: approximately 24–32px

The exact numbers may be refined in implementation, but the proportions must remain consistent.

## Grid principle

Use the 12-column grid to establish alignment between chapters, then deliberately break it where the art direction requires drama.

A luxury editorial page should feel composed, not mechanically boxed.

## Approved content spans

Typical desktop spans:

- Narrow editorial copy: 3–4 columns
- Standard body copy: 4–5 columns
- Product recommendation details: 4–5 columns
- Primary image: 6–8 columns
- Full recommendation workspace: 10–12 columns
- Product gallery: 3 columns per product across four items
- Comparison table: 8–10 columns
- Large quote: 5–7 columns

These spans are directional. Optical balance takes priority over rigid arithmetic.

## Alignment anchors

The website should maintain a small number of recurring anchors:

- Left editorial text edge
- Main content centre line
- Product-card baseline
- Right image edge
- Primary CTA axis

These anchors create continuity even when scenes vary dramatically.

## Full-bleed behaviour

Full-bleed or near-full-bleed treatment is approved for:

- Hero photography
- Real-results imagery
- Founder editorial photography
- Final cinematic CTA

Full-bleed treatment is not approved as a default for every section.

## Grid-breaking rules

Approved grid breaks include:

- A model extending beyond the central content width
- A product render overlapping a text or image plane
- A portrait occupying 7–8 columns while text sits in an offset 3-column block
- Captions or signatures positioned in an intentional blank column
- Photography extending to one viewport edge while copy remains aligned to the core grid

Grid breaks should create tension and hierarchy. They must not create accidental misalignment.

## Container discipline

Avoid placing every chapter inside a centred rounded rectangle.

Use contained surfaces only when they improve:

- Selection
- Comparison
- Grouping
- Interactive understanding

Do not use containers for:

- Emotional storytelling
- Founder biography
- Large photographic proof
- Section introductions
- Editorial quotes

## Responsive hierarchy

At smaller widths, preserve hierarchy before preserving exact geometry.

Priority order:

1. Message clarity
2. CTA prominence
3. Product and face visibility
4. Reading order
5. Visual atmosphere
6. Decorative overlap

A desktop overlap that causes mobile confusion should be removed rather than forced.

## Desktop chapter silhouettes

### Hero

- Full-width layered composition
- Copy anchored left
- Model central
- Jimmy and environmental context right

### Recommendation engine

- Contained 10–12-column decision workspace
- Strong internal structure
- Dedicated tonal field

### Hollywood method

- Wide whitespace
- Three separated editorial ideas
- Minimal surface treatment

### Real results

- Photography-led
- Asymmetrical image scale
- Limited text

### Best sellers

- Calm return to aligned product grid
- Four products maximum

### Jimmy story

- Asymmetrical editorial spread
- Oversized photography
- Narrow text column

### Comparison

- Centred, precise and minimal
- Narrower width than surrounding scenes

### Reviews

- Portrait-led staggered composition
- Not a repeated equal card row

### Routine

- Directional horizontal sequence
- Clear visual flow

### Final CTA

- Full-width dark environment
- Strong image/copy polarity

## Optical alignment

Mathematical alignment alone is insufficient.

Account for:

- Serif letterforms appearing visually offset
- Product bottles with asymmetrical pumps
- Faces requiring extra breathing room
- Drop shadows affecting apparent boundaries
- Large headlines requiring optical rather than numeric centring

## Common layout failures

Reject layouts that:

- Use the same max-width container in every chapter
- Centre every heading
- Repeat the same 4-card architecture
- Confine all imagery to rounded cards
- Use identical left/right split proportions repeatedly
- Create large unused areas without editorial intent
- Break the grid without a clear focal purpose
- Use full-bleed photography so often that it loses impact

## Success criteria

The grid system succeeds when:

- Alignment feels consistent across the full page
- Each chapter remains structurally distinctive
- Content feels calm and premium
- The user can scan without noticing the grid
- Intentional breaks create drama without disorder
- The page feels designed as one system rather than assembled from templates
