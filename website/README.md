# Sunless by Jimmy Coco — Website Creative Director Bible

This folder is the source of truth for the Sunless by Jimmy Coco website experience, luxury editorial art direction, homepage architecture, conversion system, photography language and website image-generation workflow.

The website system is designed to guide:

- Creative direction
- UX and UI design
- Ecommerce conversion design
- Website photography and product rendering
- Website copywriting
- Front-end implementation
- AI image generation for website scenes

## Core principle

This is an **evolution, not a redesign**. Approximately 95% of the existing Sunless visual identity should remain recognisable. Improvements come through hierarchy, composition, pacing, storytelling, scale, emotional rhythm, trust and guided decision-making.

## Website structure

- [`00-foundation/`](00-foundation/) — website executive summary, brand interpretation, positioning and principles
- [`01-design-system/`](01-design-system/) — website composition, grid, spacing, colour, typography and photography
- [`02-experience/`](02-experience/) — homepage narrative, customer psychology and conversion architecture
- [`03-homepage-scenes/`](03-homepage-scenes/) — individual scene specifications and image prompts
- [`04-ai-production/`](04-ai-production/) — website prompt workflow, reference protocol, consistency rules and QA
- [`05-assets/`](05-assets/) — website reference-image manifest and asset guidance

## How to use this system

1. Read the shared brand documents in [`../shared/`](../shared/).
2. Read the website foundation documents.
3. Load the relevant website design-system documents.
4. Load the homepage narrative.
5. Load only the scene document being generated.
6. Attach the approved visual references listed in the asset manifest.
7. Generate one scene at a time.
8. Evaluate the scene using the QA checklist.
9. Assemble approved scenes into the complete homepage.

Never generate the entire homepage in a single pass. Long-form image models tend to collapse distinct chapters into one continuous ivory block. The approved production method is scene-by-scene generation with a shared consistency system.
