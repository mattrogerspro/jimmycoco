# Buttons, Links and CTA Hierarchy

## Purpose

Make the next action obvious without making the email feel aggressive or crowded.

## Primary CTA

Use one dominant CTA per message. It should express the commercial or behavioural objective directly.

Examples:

- Find My Match
- Shop the Recommended Shade
- Complete My Routine
- Return to My Bag
- See Real Results

## Visual treatment

Primary buttons should use:

- matte-black or approved high-contrast fill
- live HTML text
- minimum 44px height
- generous horizontal padding
- concise label
- robust table-based implementation

## Secondary actions

Use a quieter outline button or underlined text link. A secondary action must not visually compete with the primary CTA.

## CTA placement

- Place the first CTA close to the core proposition.
- Repeat it only when the email is long enough to justify another decision point.
- Keep product CTAs directly associated with their product module.
- Do not place unrelated buttons side by side on mobile.

## Label rules

CTA labels should describe the outcome, not the interface.

Prefer:

- See My Recommendation
- Shop Malibu Beach
- Learn Jimmy's Method

Avoid:

- Click Here
- Learn More when a more specific label is available
- Shop Now repeated throughout every module

## Links

- Use underlines where a link might otherwise be mistaken for body text.
- Ensure links have sufficient contrast.
- Avoid linking whole paragraphs.
- Do not rely on colour alone.

## Button fallback

Buttons must remain understandable if border radius, custom fonts or some CSS is removed. Avoid image-only buttons.

## CTA density

Recommended maximums:

- Short single-purpose email: 1–2 CTAs
- Editorial/product email: 2–4 contextual CTAs
- Product grid: one CTA per product, with no additional competing global actions in the same visual zone

## Success criteria

CTA hierarchy succeeds when the reader can identify the intended next step instantly and secondary routes remain available without creating indecision.
