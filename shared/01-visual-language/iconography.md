# Sunless by Jimmy Coco — Iconography System

This document is the canonical source of truth for all Sunless by Jimmy Coco packaging, website, email and campaign iconography.

Use this system whenever generating, redrawing, vectorising or commissioning icons. Channel-specific documents must reference this file rather than creating conflicting icon rules.

---

## 1. Creative Direction

Sunless iconography must feel designed for an ultra-premium professional beauty brand rather than assembled from generic stock assets.

The visual language combines minimal luxury, editorial beauty restraint, Japanese cosmetic-packaging precision, Apple Human Interface clarity, Aesop simplicity, Chanel packaging refinement and Tom Ford Beauty elegance.

Every icon must look as though it was drawn by one specialist iconographer as part of one controlled family.

---

## 2. Canonical Master Prompt

Insert this complete block at the beginning of every individual icon prompt.

```text
Create one ultra-premium cosmetic packaging icon for Sunless by Jimmy Coco, a luxury professional tanning and beauty brand.

The icon must feel purpose-designed for premium salon skincare packaging and belong to one coherent luxury icon family.

CREATIVE CHARACTER

Minimal luxury.
Editorial beauty aesthetic.
Japanese cosmetic-packaging quality.
Apple Human Interface precision.
Aesop simplicity.
Chanel packaging refinement.
Tom Ford Beauty elegance.

DRAWING LANGUAGE

Use extremely clean vector linework, mathematically controlled curves, perfectly balanced proportions and subtle optical corrections.
Every curve must feel engineered rather than hand-drawn.
Every junction must be deliberate.
Every radius must belong to one consistent geometric system.
Corners should be very slightly softened and never aggressively sharp.

Do not create cartoon styling, clipart, stock-icon language, emoji characteristics, rounded app-icon styling, illustrative shading, ornamental flourishes, 3D rendering, photorealism, embossing, bevels, gradients, shadows, glow, texture, noise or paper grain.

STROKE SYSTEM

Use a consistent apparent stroke weight equivalent to 2.25–2.5 px at the master design scale.
All strokes must maintain equal visual weight after scaling.
Use subtly softened terminals only where refinement requires them.
Do not mix heavy outlines with delicate interior marks.

COLOUR SYSTEM

Primary icon colour: #3B3836.
Circular field colour: #F6F1EA.
Optional micro-accent colour: #C6A66A.
Use the accent only for one tiny functional highlight where explicitly requested.
Do not use additional colours, gradients or tonal modelling.

COMPOSITION

Place the icon inside a mathematically perfect circular field.
The circle must read as a flat packaging device, not a button.
Centre the artwork optically rather than relying only on mathematical centring.
Maintain approximately 68–72% icon coverage within the circle.
Preserve equal perceived padding on every side.
Correct for visual weight so the icon feels perfectly balanced vertically and horizontally.
The icon must remain clear at approximately 12–15 mm in print.

OUTPUT

Create one isolated icon only.
Transparent canvas outside the circular field.
Square master artwork.
Highest available resolution, ideally 4096 × 4096 px.
Crisp SVG-quality edges.
No surrounding copy, labels, captions, mockups, packaging, hands or environmental context.
```

---

## 3. System Consistency Rules

1. Use the same apparent stroke thickness across the family.
2. Use the same circle diameter, field colour and edge treatment.
3. Match perceived optical scale, not merely numeric dimensions.
4. Use one curve, corner-radius and terminal system.
5. Keep every symbol immediately understandable at small size.
6. Remove all detail that is not essential to meaning.
7. Use filled silhouettes only when they match the established family weight.
8. Generate and approve one icon at a time.
9. Use the latest approved icon as the visual reference for every subsequent icon.
10. Redraw final artwork manually as true vector geometry before production.

## Icon 01 — Professional Spray Tan

### Purpose

Communicate specialist salon application using professional spray-tanning equipment.

### Generation Prompt

```text
[INSERT THE CANONICAL MASTER PROMPT]

ICON SUBJECT — PROFESSIONAL SPRAY TAN

Create a refined luxury cosmetic icon representing professional spray tanning.
Depict a premium HVLP spray-tanning gun in an elegant side or extremely subtle three-quarter profile.

FORM

Use a compact ergonomic body, smooth controlled silhouette, clearly defined simplified nozzle, elegant trigger, proportionate lower solution cup and only the minimum hose or air connection needed for recognition.
Do not show screws, labels, branding, oversized tanks or industrial mechanical detail.

ATOMISED MIST

Show a fine controlled cosmetic mist leaving the nozzle.
Construct it from tiny evenly spaced circular droplets that begin close together and disperse gradually in a restrained tapered formation.
Reduce the number of droplets toward the outer edge to create a natural fade without transparency or gradients.

COMPOSITION

Point the nozzle right or slightly upward-right.
Balance the heavier gun and solution cup against the lighter mist using optical centring.
Keep all artwork comfortably inside the circular field.

AVOID

Paint sprayers, pressure washers, garden sprayers, airbrush pens, aggressive jets, smoke, clouds, fog, long crossing hoses and construction-tool styling.

The final icon must communicate professional beauty application, precision, flawless coverage and salon expertise.
```

# 9. Generation and Approval Workflow

1. Attach the approved packaging reference and latest approved family icon.
2. Generate one icon only.
3. Compare circle diameter, stroke weight, optical scale and internal padding.
4. Reject gradients, shadows, textures, 3D depth and unrelated colours.
5. Correct geometry manually in vector software.
6. Validate at 4096 px and approximately 15 mm print size.
7. Export SVG, print PDF and transparent PNG.
8. Record the approved asset, version and permitted claims in the shared asset manifest.

---

# 10. Quality-Control Checklist

An icon is production ready only when every answer is yes:

- Does it feel unmistakably premium?
- Does it belong to the same family as the approved icons?
- Is the circle mathematically clean and visually flat?
- Is the icon optically centred?
- Is its visual weight balanced?
- Are curves, corners and terminals consistent?
- Is the meaning immediate without supporting text?
- Has every unnecessary detail been removed?
- Is it clear at 12–15 mm?
- Are colours limited to the approved palette?
- Are gradients, shadows, glow and texture absent?
- Can it be reconstructed cleanly as true vector artwork?
- Is every associated product claim approved and supportable?

If any answer is no, the icon is not production ready.
