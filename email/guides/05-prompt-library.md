# Prompt library — ready-to-use requests

Copy, adapt, and send. Each prompt works as-is; the bracketed parts are where you make it yours. One request, one job — don't bundle unrelated asks.

## Create a new campaign

> Build a [5-email] [cold outreach / onboarding / win-back] campaign for [market/city] targeting [audience], driving toward [one primary outcome — e.g. trial requests]. Offer: [hook, if known]. Use [comparable campaign] as the closest reference.

## Localise an existing campaign

> Localise [campaign id] for [new market]. Keep the strategy but adapt the seasonal timing, cultural references, terminology and compliance basis for [market]. Don't just swap the place names.

## Edit copy

> In [campaign id], revise email [number]: [what to change and why — e.g. "the CTA competes with the secondary link; make the trial request the only ask"]. Keep sequence.md and email-data.json in step, and rebuild.

## Add follow-ups

> Extend [campaign id] with [2] follow-up emails for non-responders: [angle — e.g. one proof-led, one respectful last call]. Match the existing cadence rhythm and stop rules.

## Regenerate after changes

> Rebuild the HTML for [campaign id] and confirm the build validator, tests and template drift check all pass.

## Compare with Resend

> Run the read-only template check and tell me which campaigns have drifted from their published Resend templates. Don't publish anything.

## Tips that improve every request

- **Name the outcome, not the tactic.** "Drive trial requests" beats "write persuasive emails".
- **Say what's fixed.** If the cadence, market or offer is decided, state it — everything unstated gets a default or a token.
- **Never supply guesses as facts.** If you don't know the price or terms, say so; they'll be tokenised for approval, not invented.
- **Draft is the default.** Every request produces an unsendable draft for human review. Publishing to Resend, enabling sending or importing contacts always needs your explicit, separate approval.
