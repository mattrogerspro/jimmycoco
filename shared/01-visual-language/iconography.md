# Sunless by Jimmy Coco — Iconography System

This document is the canonical source of truth for all Sunless by Jimmy Coco packaging, website, email and campaign iconography.

Use this system whenever generating, redrawing, vectorising or commissioning icons. Channel-specific documents should reference this file rather than creating conflicting icon rules.

---

## 1. Creative Direction

Sunless iconography must feel designed for an ultra-premium professional beauty brand rather than assembled from generic stock assets.

The visual language should combine:

- minimal luxury
- editorial beauty restraint
- Japanese cosmetic-packaging precision
- Apple Human Interface clarity
- Aesop simplicity
- Chanel packaging refinement
- Tom Ford Beauty elegance

Every icon must appear as part of one bespoke system created by the same iconographer.

The icons must never feel playful, cartoon-like, decorative for decoration’s sake, industrial, technical in a harsh way, or like app-store glyphs.

---

## 2. Canonical Master Prompt

Use the following block at the beginning of every Sunless icon-generation prompt.

```text
Create one ultra-premium cosmetic packaging icon for Sunless by Jimmy Coco, a luxury professional tanning and beauty brand.

The icon must feel purpose-designed for premium salon skincare packaging and must belong to one coherent luxury icon family.

CREATIVE CHARACTER

Minimal luxury.
Editorial beauty aesthetic.
Japanese cosmetic-packaging quality.
Apple Human Interface precision.
Aesop simplicity.
Chanel packaging refinement.
Tom Ford Beauty elegance.

DRAWING LANGUAGE

Use extremely clean vector linework, mathematically controlled curves, perfectly balanced proportions and subtle optical corrections.

Every curve must feel engineered rather than hand-drawn.
Every junction must be deliberate.
Every radius must belong to one consistent geometric system.
Corners should be very slightly softened and never aggressively sharp.

Do not create:

- cartoon styling
- clipart
- stock-icon language
- emoji characteristics
- rounded app-icon styling
- illustrative shading
- ornamental flourishes
- 3D rendering
- photorealism
- embossed effects
- bevels
- gradients
- shadows
- glow
- texture
- noise
- paper grain

STROKE SYSTEM

Use a consistent apparent stroke weight equivalent to 2.25–2.5 px at the master design scale.

All strokes must maintain equal visual weight after scaling.
Use rounded or subtly softened terminals only where required for refinement.
Do not mix heavy outlines with delicate interior marks.

COLOUR SYSTEM

Primary icon colour: #3B3836.
Circular field colour: #F6F1EA.
Optional micro-accent colour: #C6A66A.

Use the accent only for a tiny functional highlight such as one cosmetic sparkle.
Do not use additional colours.
Do not introduce gradients or tonal modelling.

COMPOSITION

Place the icon inside a mathematically perfect circular field.
The circle must read as a flat packaging device, not a button.

Centre the artwork optically rather than relying only on mathematical centring.
Maintain approximately 68–72% icon coverage within the circle.
Preserve equal perceived padding on every side.
Correct for visual weight so the icon feels perfectly balanced vertically and horizontally.

The final icon must remain legible at approximately 12–15 mm in print while retaining enough precision for large-format digital use.

OUTPUT

Create a single isolated icon only.
Transparent canvas outside the circular field.
Square master artwork.
Highest available resolution, ideally 4096 × 4096 px.
Crisp SVG-quality edges.
No surrounding copy, labels, captions, mockups, packaging, hands or environmental context.
```

---

## 3. System Consistency Rules

Every icon in the family must obey the following requirements:

1. Use the same apparent stroke thickness.
2. Use the same circular field diameter and edge treatment.
3. Occupy the same perceived optical area.
4. Follow the same curve, corner-radius and terminal logic.
5. Use the same charcoal, ivory and optional champagne-gold palette.
6. Remain readable at small packaging scale.
7. Avoid unnecessary interior detail.
8. Communicate one idea immediately.
9. Feel elegant before it feels descriptive.
10. Never resemble an unrelated stock icon inserted into the set.

When generating several icons, create and approve them one at a time. Use the first approved icon as the visual reference for all subsequent icons.

# 4. Core Professional Spray Tan Product Icons

## Icon 01 — Professional Spray Tan

### Purpose

Communicate professional salon application using specialist spray-tanning equipment.

### Generation Prompt

```text
[INSERT THE CANONICAL MASTER PROMPT]

ICON SUBJECT — PROFESSIONAL SPRAY TAN

Create a refined luxury cosmetic icon representing professional spray tanning.

Depict a premium HVLP spray-tanning gun in an elegant side or extremely subtle three-quarter profile.

The object must read immediately as specialist beauty equipment rather than a DIY paint sprayer.

FORM REQUIREMENTS

- compact, refined spray-gun body
- smooth controlled silhouette
- clearly defined but simplified nozzle
- elegant trigger geometry
- proportionate lower solution cup
- minimal indication of the air or hose connection only where needed
- no unnecessary mechanical components
- no screws, labels, branding or industrial detailing

The spray gun should feel lightweight, precise, ergonomic and appropriate for a luxury tanning salon.

ATOMISED MIST

Show a fine controlled mist leaving the nozzle.
Construct the mist from very small, evenly spaced circular droplets.
The droplets should begin close together and disperse gradually outward in a refined tapered formation.
Use fewer droplets toward the outer edge to create a natural visual fade without using transparency gradients.

The mist must look delicate and cosmetic, not forceful or industrial.

COMPOSITION

Angle the gun so the nozzle points toward the upper-right or directly right, depending on the strongest optical balance.
Keep the gun and mist together within approximately 70% of the circular field.
Ensure the mist does not touch the circular edge.
Balance the heavier solution cup against the lighter spray pattern using optical centring.

AVOID

- paint sprayers
- pressure washers
- garden sprayers
- airbrush pens
- construction tools
- oversized tanks
- aggressive spray jets
- clouds, smoke or fog
- excessive engineering detail
- hoses crossing the circle

The final symbol must communicate professional beauty application, precision, flawless coverage and salon expertise.
```

## Icon 02 — One Litre

### Purpose

Communicate a professional one-litre salon-size tanning solution bottle.

### Generation Prompt

```text
[INSERT THE CANONICAL MASTER PROMPT]

ICON SUBJECT — ONE-LITRE PROFESSIONAL SOLUTION

Create a minimal luxury cosmetic bottle icon representing a professional one-litre Sunless spray-tan solution.

Use the actual Jimmy Coco one-litre product bottle as the proportional reference whenever an approved product photograph is supplied.

The icon must reproduce the bottle’s recognisable overall proportions without reproducing labels, text, logos or surface decoration.

BOTTLE FORM

- tall premium cylindrical body
- perfectly symmetrical front elevation
- softly rounded shoulders
- controlled transition from shoulder to neck
- medium-height neck
- simple screw-cap silhouette
- subtly softened lower corners
- stable flat base
- elegant professional salon proportions

The body should feel substantial enough to represent one litre while remaining refined and vertically elegant.

DRAWING APPROACH

Prefer one clean filled silhouette in #3B3836.
Use no interior label panel unless an extremely subtle negative-space contour is necessary to clarify the vessel shape.
Do not add measurement markings, highlights, reflections or liquid level indicators.

COMPOSITION

Centre the bottle optically within the circular field.
Account for the visual weight of the cap and shoulders so the bottle does not appear top-heavy.
Use approximately 68–70% of the circle height, leaving generous equal breathing room above the cap and below the base.

AVOID

- generic shampoo bottles
- pump dispensers
- dropper bottles
- perfume bottles
- square chemical containers
- medicine bottles
- narrow beverage bottles
- labels
- logos
- embossing
- textures
- reflections
- transparent glass effects

The finished icon must communicate professional quantity, salon value, premium formulation and product authority.
```

## Icon 03 — Medium / Dark 10% DHA Shade Badge

### Purpose

Communicate the product shade and DHA strength as a premium cosmetic shade identifier.

### Generation Prompt

```text
Create one ultra-premium cosmetic shade badge for Sunless by Jimmy Coco.

This is a flat luxury packaging badge, not an illustration and not an app icon.

BADGE GEOMETRY

Construct a mathematically perfect circular badge.
Use a precise outer ring in #3B3836.
Use a flat inner fill in #44403D.
Maintain perfectly even concentric spacing between the outer edge, ring and inner field.

The ring must feel refined and restrained rather than heavy.
Do not use bevels, highlights, gradients, shadows or texture.

TYPOGRAPHY

Set the wording exactly as follows:

MEDIUM
/
DARK
10%

Alternatively, where the approved packaging hierarchy requires a more compact arrangement, use:

MEDIUM / DARK
10%

Use a refined geometric sans-serif typeface with excellent legibility and neutral luxury character.
Use uppercase letters.
Apply precise optical kerning and tracking.
Centre every line optically.

Use #F6F1EA for the lettering.
The typography must remain crisp and readable at small packaging scale.

HIERARCHY

“MEDIUM” and “DARK” should carry the primary visual emphasis.
The slash must be smaller and carefully spaced.
“10%” should form a clear secondary line with slightly stronger numeric emphasis than the percent sign.

Do not add an unnecessary divider unless it materially improves the approved layout.
Do not add decorative gold rings, extra borders, stars, dots or ornamental marks.

COMPOSITION

Use generous internal breathing room.
The typography must never feel squeezed against the ring.
Balance the line block vertically so the complete badge appears calm, centred and authoritative.

OUTPUT

Single isolated badge only.
Transparent background outside the badge.
Square master artwork at the highest available resolution, ideally 4096 × 4096 px.
SVG-quality edges.

The final badge should resemble a bespoke luxury shade marker used on premium professional beauty packaging.
```

### Typography Control Note

AI image models can distort text. For production artwork, generate the circular badge geometry separately and typeset the wording manually in Figma, Illustrator or another vector application using the approved Sunless type system.

The generated badge should therefore be treated as a layout reference unless every character is verified manually.

# 5. Generation and Approval Workflow

Use the following process for every icon:

1. Attach the approved packaging reference and the latest approved icon from this family.
2. Generate one icon only.
3. Compare stroke weight, circle diameter, optical scale and internal padding against the approved master.
4. Reject any image that introduces gradients, shadows, texture, 3D depth or unrelated colour.
5. Correct the geometry manually in vector software where necessary.
6. Validate legibility at both 4096 px and approximately 15 mm print size.
7. Export final production files as SVG, PDF and transparent PNG.
8. Record the approved asset in the shared asset manifest.

---

# 6. Quality-Control Checklist

An icon is approved only when every answer below is “yes”.

- Does it feel unmistakably premium?
- Does it belong to the same family as the other approved icons?
- Is the circle mathematically clean and visually flat?
- Is the icon optically centred?
- Is the visual weight balanced?
- Are the curves and terminals consistent?
- Is the symbol immediately understandable?
- Is unnecessary detail removed?
- Is it still clear at small packaging scale?
- Are the colours limited to the approved palette?
- Are gradients, shadows, glow and texture completely absent?
- Can the artwork be reconstructed cleanly as a true vector?

If any answer is “no”, the icon is not production ready.
