# Sunless Packaging Icon Set

Canonical production artwork for the 14 core Sunless by Jimmy Coco packaging and professional product icons.

All SVGs use:

- 1024 × 1024 viewBox
- circular field `#F6F1EA`
- primary mark `#3B3836`
- optional accent `#C6A66A`
- transparent canvas outside the circular field
- consistent rounded stroke language
