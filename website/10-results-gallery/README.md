# Results Gallery System

This folder defines the Sunless by Jimmy Coco proof and transformation experience across gallery, result-detail, product-linking and mobile surfaces.

The purpose is to turn before-and-after content into credible, useful buying evidence rather than a generic social gallery.

## Core principle

Every result must answer:

- What did the customer start with?
- What product was used?
- Which shade or variant was selected?
- How many coats were applied?
- How long did the result develop?
- Under what lighting was the image captured?
- What should a similar customer realistically expect?

## Non-negotiable

The gallery must never imply that every customer will achieve an identical result. It must show credible variation, preserve real skin texture and explain the conditions behind each outcome.
